📦 מה יש כאן ומה דורש המשך

יש כאן שיטת לימוד כתובה וכלי ניהול קבצים מקומיים. האלגוריתמים הם מתכוני עיון המיועדים להפעלה בידי הלומד או בשיחה. כלי Python אינם מנוע שמפרש תורה או מאמת מקורות בעצמו.

עמוד הקריאה פועל ללא התקנות וללא חיבור רשת; פתיחת מקורות חיצוניים דורשת רשת. הוא משתמש בעותק HTML של המסמכים שהוכן בעת האריזה. לאחר עריכת Markdown פותחים את הקבצים בעורך; העמוד לא מתעדכן מעצמו. לבנייה מחודשת הרץ python3 tools/build_reader.py.

התשובה המקורית נשארה בגרסה 0.0.1 ובזמן המקורי שלה. חבילת המאגר היא גרסה 0.0.2. סימון משימות בעמוד נשמר רק בדפדפן הנוכחי; כפתור ייצוא מוריד צילום מצב JSON ואינו עורך את TODO.md.

💻 עבודה עם Python — רשות

נדרש Python 3.9 ומעלה, ללא ספריות צד שלישי. פתח מסוף בתיקיית המאגר:

python3 tools/parshapulse.py check
python3 tools/build_reader.py
python3 tools/parshapulse.py new-week --slug chayei-sarah-5787 --name "חיי שרה" --reference "בראשית כג–כה" --date 2026-11-07
python3 tools/parshapulse.py package --output ParshaPulse-local.zip

הכלי יוצר טיוטת שבוע; הוא אינו בודק שהפרשה מתאימה לתאריך. לפני לימוד לפי תאריך יש להשלים אימות לוח ומנהג.

🛠️ כלים מקומיים

Python 3.9 ומעלה; הספרייה התקנית בלבד. אין קריאות רשת ואין צורך במפתחות API.

מתוך שורש המאגר:

python3 tools/parshapulse.py check
python3 tools/build_reader.py
python3 tools/parshapulse.py new-week --slug vayera-next-study --name "וירא" --reference "בראשית יח–כב" --date 2026-10-31
python3 tools/parshapulse.py package --output ParshaPulse-local.zip
  • check: בודק קבצים נדרשים, גרסה, 28 מזהי אלגוריתמים, 120 משימות, התאמת TODO ונתוני המשימות וקישורי Markdown יחסיים. אינו בודק נכונות תורנית או זמינות קישורים חיצוניים.
  • new-week: יוצר תיק עם README, תבנית מקטע, תבנית מפגש ו־week.json. מסרב לדרוס תיק קיים ומאמת מבנה תאריך וסלאג. תאריך אינו משמש לחישוב פרשה; סטטוס הלוח תמיד pending.
  • package: יוצר ZIP חדש ואינו דורס קובץ קיים. מחריג private, .git, מטמון Python וקובצי ZIP; אין בכך תחליף לבדיקת תוכן אישי שהוכנס לתיקייה ציבורית אחרת.

build_reader.py בונה מחדש את START-HERE.html מתוך מסמכי Markdown ונתוני המשימות. הוא משתמש במרנדר מקומי לכותרות, פסקאות, רשימות, טבלאות, ציטוטים וקוד; אינו מימוש מלא של כל הרחבות Markdown. אין עדכון אוטומטי בעת עריכה, ויש להריץ אותו אחרי שינויי תוכן.
