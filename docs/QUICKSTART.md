# 🚀 מתחילים כאן

## מפגש ראשון — עשרים דקות

1. בחר יחידה של 5–10 פסוקים וקרא אותה ברצף.
2. כתוב שאלה אחת שאפשר להראות את הבסיס שלה בכתוב.
3. בחר אלגוריתם: 01 למיפוי, 05 להשוואת מפרשים, 13 למידה או 11 לחידוש.
4. פתח את קובץ האלגוריתם מתוך [המפתח](../algorithms/INDEX.md).
5. העתק את [תבנית המקטע](../templates/SEGMENT.md).
6. בצע את השלבים ורשום מה טרם נבדק.
7. סיים בתובנה אחת ובשאלת המשך אחת.

## הודעה לפתיחת מפגש חוזר

> ממשיכים ב־ParshaPulse. הפרשה: ___. טווח הפסוקים: ___. היום נבחר PP-___. השאלה: ___. הנה סיכום המפגש האחרון והמקורות שכבר נבדקו: ___. הפק מקטע לפי התבנית והפרד מקור, פירוש, חידוש ויישום.
