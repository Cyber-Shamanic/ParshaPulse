# 🗃️ ניהול המאגר ופרסום ב־GitHub

## תיקיות

- `algorithms/`: מתכוני הלימוד, בארבעה קבצים לכל משפחה.
- `docs/`: מתודולוגיה, התשובה המקורית והוראות.
- `templates/`: מסמכים להעתקה.
- `examples/vayera/`: דוגמה ראשונה.
- `weeks/`: תיקי שבוע שנוצרים מקומית.
- `data/`: קטלוג אלגוריתמים ומשימות במבנה JSON.
- `tools/`: כלי Python לניהול ובדיקה.

## העלאה ראשונה

1. צור מאגר בשם `ParshaPulse` בחשבונך.
2. העלה את תוכן התיקייה, כך ש־README.md נמצא בשורש.
3. ודא שקובצי לימוד אישיים לא צורפו לפרסום.
4. בחר רישיון לתוכן המקורי ולקוד, לאחר בחינת [הודעת הזכויות](../LICENSE-NOTICE.md).
5. אם משתמשים ב־Git מקומי, אפשר לבצע מתוך התיקייה:

```bash
git init
git add .
git commit -m "Create ParshaPulse v0.0.2"
git branch -M main
```

יש להוסיף remote רק עם כתובת המאגר שנוצרה בפועל. הפעולות אינן מבוצעות אוטומטית בחבילה.

## עדכון גרסה

עדכן יחד VERSION, project.json, README ו־CHANGELOG. עדכן סטטוס ב־TODO וב־data/tasks.json. רשום מה השתנה ולמה. עמוד הקריאה מכיל צילום מצב של הקבצים בזמן האריזה; אין סנכרון אוטומטי עם שינויי Markdown; הרץ `python3 tools/build_reader.py` אחרי עריכת התוכן.

## פרטיות

שמור שאלות אישיות רגישות בתיקייה `private/`, המוחרגת ב־.gitignore. החרגה מונעת צירוף עתידי ב־Git בלבד ואינה מסירה קובץ שכבר פורסם; בדוק לפני העלאה. כלי האריזה המקומי מחריג private ו־.git.
